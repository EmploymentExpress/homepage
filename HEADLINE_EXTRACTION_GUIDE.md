# Headline Guide (superseded)

This file used to describe a PDF "category-suffix" headline system
(`extract_pdf_headlines.py`, headlines like `Assistant Recruitment [SC, ST]`).
That system was never part of the live pipeline — the script does not exist in
this repository — and the design has been **superseded**.

## The live headline rule

Job-details headings are generated by the shared implementation in
`scripts/short_headlines.py` (Python) and its JS mirror in `index.html`
(`shortJobHeadline()` / `jobDisplayHeadline(job)`). Both must produce identical
output, and the guard tests in `tests/test_short_headlines.py` keep them in
sync.

**Recruitment notices:**

```
<Department name> <Post name(s)> Recruitment | Apply Online
<Department name> Various Post Recruitment | Apply Offline
```

| Posts in the notice | Headline shows |
| --- | --- |
| 1 post | that post name (`PGIMER Chandigarh Nursing Officer Recruitment \| Apply Online`) |
| 2–4 different posts | all of them, comma separated (`PGIMER Chandigarh DEO, MTS, Pharmacist Recruitment \| Apply Online`) |
| more than 4 posts | `Various Post` (`PGIMER Chandigarh Various Post Recruitment \| Apply Offline`) |
| no post named | department only (`PGIMER Chandigarh Recruitment \| Apply Online`) |

**Non-recruitment notices:** `<Department name> <Notice type>` — for example
`SBI Admit Card`, `PGIMER Chandigarh Result`. Interview call letters are
admit-card notices and render in the Admit Card column.

The authoritative, complete rule — department short-name logic, apply-mode
detection, notice-type vocabulary, hard rules — lives in **AGENTS.md →
"Job-details headline rule"**. A before/after demo of every live heading can be
regenerated with `python scripts/preview_short_headlines.py`
(writes `docs/short-headline-demo.html` / `.md`).
